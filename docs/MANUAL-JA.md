# 操作マニュアル

立体人形装置（ODM Poser）の画面の使い方です。画面で「?」を押すと、いまの端末向けの操作の一覧（操作のヒント）も開けます。

English: [MANUAL.md](MANUAL.md)

## 画面の見かた

- **図**：正面（カメラ）と側面図。左上に元に戻す・やり直す、モード、3軸ハンドル、カーソルが、右上に表示の切り替え（関節の限界・隠れ線・胴体を立体・側面図・操作欄・明るさ・言語・操作のヒント）が出ます。
- **操作欄**：図の外側。分類（作る・見る・出す・ODM-Poserについて）→ タブ → 各項目の順に開きます。
- 図と操作欄の境目をドラッグすると広さを変えられます（ダブルクリック・ダブルタップで戻す）。

### 端末ごとの並び

| 端末 | 図 | 操作欄 |
|------|----|--------|
| パソコン・横長の画面 | 左 | 右（上の「操作欄」「メニュー」のボタンで左・上・下にも） |
| タブレット・縦のモニター（縦向き） | 上（高さの50〜85%） | 下。分類バーとタブ2段の上に、項目が横に並ぶ。「⇅ 上下」で分類バーごと上へ |
| スマホ（縦向き） | 画面いっぱい | 下に分類バー。押すと全画面のメニューが開き、上に簡略表示。つまみを下へドラッグで閉じる |
| スマホ・タブレット（横向き） | 左 | 右（分割表示で上下にも） |

操作欄の位置・図の広さは、縦向きと横向きで別々に覚えます。

## モード

図の左上のボタンか、関節・物のクリックで切り替えます。

| モード | できること |
|--------|-----------|
| ポーズ | 関節を動かす（3軸ハンドルは回転と、手足・肩・股の移動） |
| 体格 | 骨の長さ・丸の太さ・肩や股の幅を変える（3軸ハンドルは変形） |
| カメラ | カメラとレンズ（パース）を動かす |
| 配置 | 物体・小物・人物全体を動かす |

### クリックで自動的にモードを切り替える

ポーズの欄の同名の設定（最初はオン）で、クリックしたものに合わせてモードが変わります。

| クリックしたもの | 変わるモード |
|------------------|-------------|
| 関節（配置・カメラから） | ポーズ |
| Shift＋関節 | 体格（ポーズ⇄体格を切り替え） |
| 腰の真ん中 | 配置（人物全体を動かす。3軸ハンドルは移動） |
| Shift＋腰の真ん中 | ポーズ（体ごと回す。3軸ハンドルは回転） |
| 物体・小物 | 配置（その物を選ぶ） |
| 何もない所（ポーズ・体格から） | カメラ |
| 何もない所（配置） | 物の選択を外す |

## カーソル：ドラッグとハンド

図の左の「ドラッグ」「ハンド」（V・H キー）。

- **ドラッグ**：何もない所からのドラッグで、囲んだ物を選びます（Shift＋で足す）。
- **ハンド**：どこをドラッグしてもカメラが回ります（Shift＋で動く）。
- **カメラモードはいつもハンド**です。ドラッグせずに離すとモードが切り替わります（上の表）。

## 3軸ハンドル

選んだ関節・物に、移動・回転・変形の矢印と輪を出します。図の左の「3軸ハンドル」「解除」で出す・隠す、「移動」「回転」「変形」（G・R・S キー）で切り替えます。

- 矢印（移動）は、どこにあっても場面の X・Y・Z に沿います。
- 輪（回転）と四角（変形）は、選んだものの向きに沿います。関節では関節の軸（Y が骨の向き、Z が体の前の向き）、物体・小物では物体の向き（回した向き）です。四角は物体の幅・高さ・奥行きをそれぞれ伸ばします。いくつかまとめて選んだときの輪は、場面の X・Y・Z です。
- ポーズモードで肩・股を選ぶと、移動の矢印も使えます。胸・腰からの骨の長さを保ったまま、関節の限界の中（肩はすくめる・前後、股はわずか）で動くので、体格は変わらずに、胴体と腰の台形だけが歪みます。
- 体格モードで頭を選ぶと、四角は「長さ」「幅」「奥行き」の3つになり、頭の球そのものをその向きに伸ばし・縮めます（体格のタブの「頭の形」と同じ。頭の大きさと首の長さはそのまま）。伸ばした頭は、頭の向きのとおりに楕円の球として描かれ、顔の十字も伸ばした形に沿います。
- ポーズモードの関節では、緑（Y）の輪は骨を軸にねじります（関節パネルの「ねじり」と同じ。肘なら上腕を軸に前腕が回り、頭ならその場で左右を向きます）。腰の緑の輪は、体ごと縦の軸で回します。
- 輪が重なっているところでは、押した所にいちばん近い輪を掴みます（同じくらいなら緑）。
- 掴んだ矢印・輪は太くなり、ほかは薄くなります。
- ハンドルの大きさは画面に合わせます（スマホで約1.35倍、タブレットで1.5倍、大きい画面で1.75倍）。
- ハンドルを出している間は、関節や物のドラッグは選ぶだけで、動かすのはハンドルです。
- 配置モードで物を選ぶと「支点」が使えます。押している間は移動ハンドルが回転の中心を動かします（数値は設置のタブ。[小物・物体](PROPS-JA.md)）。

## 物を選ぶ・編集する（配置モード）

選ぶ：クリック、囲む、Ctrl（⌘）＋クリックで足す・外す。人物も、囲むか Ctrl＋クリックで一緒に選べます（ほかの人物も。選んだ人物は点線の枠で囲まれます）。いくつか選ぶと、1つの物の支点を中心に、3軸ハンドルでまとめて動かし、X・Y・Z の軸でまとめて回せます。中心になるのは最後に足した物（人物なら腰）で、Ctrl＋Shift＋クリックでほかの物に変えられます（選択を外すと元に戻ります）。削除・切り取り・コピーは物だけにかかり、人物はそのまま残ります。ほかのモードで Ctrl＋クリックすると、配置モードに切り替わります。

Ctrl＋人体をクリック（何も選んでいないとき）：腰を選んで、人物全体を動かします（そのままドラッグで床の上を動き、3軸ハンドルなら矢印と輪で）。

| 操作 | キー | 図の左のボタン |
|------|------|---------------|
| 外す | Delete（Backspace） | 削除 |
| 切り取り・コピー・貼り付け | Ctrl＋X・C・V | 切り取り・コピー・貼り付け |

狭い画面（スマホ横向きなど）では、左のメニューが2列でも入りきらないので、「…」で3軸ハンドルと、カーソル・編集のボタンを入れ替えます。

## 面に立つ・貼り付く

人物を、床・壁・天井と、置いた物体の面（斜面も）に立たせられます。壁では横向きに、天井では逆さに、斜面では面に垂直に、体ごと面に合わせます。

面に着くのは、体のいちばん近い所・低い所です。ポーズによって、足の裏だけでなく、膝・手・頭・腰なども着きます（関節の丸の太さ込み）。物体の面（上面も）・壁・天井に立っているあいだは、ポーズを変えても、いちばん低い所が面に着いたままです。片足を上げればもう片方の足が、両膝をつけば膝が着きます。床では、配置のタブの「接地」の設定のとおりです。腰を固定（ピン）していると、固定が優先されます。

- 配置モードで腰をドラッグして体を面に近づける（体のどこかが 15cm 以内）と、その面に立ちます（配置のタブの「腰を動かすと近くの面に立つ」でオン・オフ）。
- 配置のタブか設置のタブの「面をクリックして立つ」を押してから、面をクリックします（Esc でやめます）。
- 設置のタブで物体を選び、「近い面に立つ」で、人物の体にいちばん近いその物体の面に立ちます。「この上に立つ」も、上面にいちばん低い所を着けて、そのまま貼り付きます。
- 体が面の反対側へ抜けたり、逆さに反転したりしません。立っている面の裏へ押し込んでも、その面に戻ります。腰が面の裏にある面と、体が逆さ・裏向きになる面（天井や物体の下側）には、腰を近づけても立ちません。逆さにも立たせたいときは、配置のタブの「逆さ・裏向きになる面にも立つ」をオンにするか、「面をクリックして立つ」で面をクリックします。
- 接地の初期値は「床・物体の上にめり込まない」です（新しく始めたとき・リセットしたとき）。
- 床以外の面に立っているあいだは、腰をドラッグすると面に沿って動きます。3軸ハンドルなどで面から離すと、貼り付きが外れます。
- 「体をまっすぐに戻す」で、傾いた体をまっすぐにします。

## 体格とサイズ

「体格」のタブに、性別・身長・全体の大きさと、部位ごとのサイズ（部位の固定、頭と胴体、腕と脚、頭の形）をまとめました。身長と頭身は「体格」の欄に1つにまとめ、スライダーで変えられます。「身長・頭身・各部を変えるとき保つもの」で、頭身を保つ（全身が同じ割合で）か、身長を保つ（残りの体で合わせる）かを選べます。
小物の大きさ（3軸）と部位ごとの長さは、装備と設置のタブにあります。

「女性」「男性」で性別を変えても、それまでの調整（部位の長さ、左右の違い、太さ、頭の大きさ）は残ります。性別の差の割合だけ、各部と身長が変わります。
性別の初期の体格にするときは、リセットのタブの「↺ この人物を性別の初期値に戻す」か、体格プリセットを使います。

## パース定規とガイド図形

定規のタブで1点・2点・3点透視の線を出します。設置のタブで「ガイドとして置く（パース定規）」にして図形を置くと、
定規の向きにそろったガイド図形になります（直方体・円柱・角柱・角錐など、いくつでも）。

- ガイドは定規を出しているときだけ見え、定規の色で描かれ、辺が消失点まで延びます。アタリ画像には入らず、定規の画像に入ります。
- 3軸ハンドルの矢印・四角は、ガイドの辺の向きに沿います。「変形」では引いた側の辺だけが延び、反対側は動きません（透視していない辺も、高さや幅を変えられます）。
- ガイドはパース定規といつもつながっています。「回転」でガイドを回すと、パース定規とほかのガイドも一緒に回ります。前後・横に倒すと消失点がアイレベルから外れ、倒した箱の見え方になります。定規のタブの「定規を床に立てる」で倒れを戻せます。1点透視では定規はカメラの正面を向くので、左右には回りません。
- 「定規を床のグリッドにスナップ」をオンにすると、定規の向きが床のグリッドの線にそろい、90° ずつ回ります。ガイドを動かすと、角がグリッドの交点（40cm おき）に、底が床に吸い付きます。
- ガイドでない物体・小物は自由に回せます。「物体を定規にスナップ」がオンなら、定規の向きから ±5° 以内に来たときだけ吸い付きます。
- カメラの傾きを変えると、パース定規も景色と一緒に傾いて描かれます。
- 前の版の「ガイド立方体」は、開くとガイドの直方体になります。

## 置く前の大きさ

設置のタブと装備のタブでは、置く前（持たせる前）に、プレビューの薄い破線を見ながら大きさを決められます。
図形は幅・高さ・奥行き（角柱・角錐は角の数と天面）、小物は大きさ・X・Y・Z と部位ごとの長さ。置くとその大きさになります。

配置モードで何も選んでいないときは、3軸ハンドル（移動・回転・変形・支点）がプレビューに出ます。動かした位置・向き・大きさ・支点のまま「置く」で置けます。種類を変えると、プレビューは初めの位置に戻ります。

種類の欄のいちばん上は「ニュートラル（何も選ばない）」で、プレビューもハンドルも出ません。タブを開いたときと、置いた（持たせた）あとはニュートラルに戻るので、置いた物をそのまま動かせます。続けて置くときは、もう一度種類を選びます。分類を選び直すと、その最初の種類になります。

## カメラ

カメラのタブの「カメラの向き」は左右・上下・傾き（角度）で、その場でカメラを回します。「カメラの位置」は左右・上下・前後（cm）で、向きを変えずにカメラを動かします。


| 操作 | すること |
|------|---------|
| ホイール | 拡大・縮小（物の上でも） |
| Ctrl＋Alt＋ホイール | レンズ（広角ほどパースが強い） |
| 中ボタン／Alt＋ドラッグ | カメラを回す（Shift＋で動かす、Ctrl＋で拡大） |
| テンキー 1・3・7 | 正面・右から・上から |
| 2本指（スマホ） | つまんで拡大・動かして移動 |
| カメラパッド（スマホ） | 左下で回す、右下で動かす、右端で拡大 |
