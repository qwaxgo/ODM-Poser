# 操作マニュアル

立体人形装置（ODM Poser）の画面の使い方です。画面で「?」を押すと、いまの端末向けの操作の一覧（操作のヒント）も開けます。

English: [MANUAL.md](MANUAL.md)

## 画面の見かた

- **図**：正面（カメラ）と側面図。左上に元に戻す・やり直す、モード、3軸ハンドル、カーソルが、右上に表示の切り替え（関節の限界・隠れ線・胴体を立体・側面図・操作欄・明るさ・言語・操作のヒント）が出ます。
- **操作欄**：図の外側。分類（作る・見る・出す・ODM-Poserについて）→ タブ → 各項目の順に開きます。
- 図と操作欄の境目をドラッグすると広さを変えられます（ダブルクリック・ダブルタップで戻す）。

### 端末ごとの並び

| 端末 | 図 | 操作欄 |
|------|----|--------|
| パソコン・横長の画面 | 左 | 右（上の「操作欄」「メニュー」のボタンで左・上・下にも） |
| タブレット・縦のモニター（縦向き） | 上（高さの50〜85%） | 下。分類バーとタブ2段の上に、項目が横に並ぶ。「⇅ 上下」で分類バーごと上へ |
| スマホ（縦向き） | 画面いっぱい | 下に分類バー。押すと全画面のメニューが開き、上に簡略表示。つまみを下へドラッグで閉じる |
| スマホ・タブレット（横向き） | 左 | 右（分割表示で上下にも） |

操作欄の位置・図の広さは、縦向きと横向きで別々に覚えます。

## モード

図の左上のボタンか、関節・物のクリックで切り替えます。

| モード | できること |
|--------|-----------|
| ポーズ | 関節を動かす（3軸ハンドルは回転と、手足の移動） |
| 体格 | 骨の長さ・丸の太さ・肩や股の幅を変える（3軸ハンドルは変形） |
| カメラ | カメラとレンズ（パース）を動かす |
| 配置 | 物体・小物・人物全体を動かす |

### クリックで自動的にモードを切り替える

ポーズの欄の同名の設定（最初はオン）で、クリックしたものに合わせてモードが変わります。

| クリックしたもの | 変わるモード |
|------------------|-------------|
| 関節（配置・カメラから） | ポーズ |
| Shift＋関節 | 体格（ポーズ⇄体格を切り替え） |
| 物体・小物 | 配置（その物を選ぶ） |
| 何もない所（ポーズ・体格から） | カメラ |
| 何もない所（配置） | 物の選択を外す |

## カーソル：ドラッグとハンド

図の左の「ドラッグ」「ハンド」（V・H キー）。

- **ドラッグ**：何もない所からのドラッグで、囲んだ物を選びます（Shift＋で足す）。
- **ハンド**：どこをドラッグしてもカメラが回ります（Shift＋で動く）。
- **カメラモードはいつもハンド**です。ドラッグせずに離すとモードが切り替わります（上の表）。

## 3軸ハンドル

選んだ関節・物に、移動・回転・変形の矢印と輪を出します。図の左の「3軸ハンドル」「解除」で出す・隠す、「移動」「回転」「変形」（G・R・S キー）で切り替えます。

- 矢印・輪・四角は、物の向きによらず、いつも場面の X・Y・Z に沿います。回転も X・Y・Z の軸のまわりです。四角（変形）は、その軸にいちばん近い物の辺を伸ばします。
- 掴んだ矢印・輪は太くなり、ほかは薄くなります。
- ハンドルの大きさは画面に合わせます（スマホで約1.35倍、タブレットで1.5倍、大きい画面で1.75倍）。
- ハンドルを出している間は、関節や物のドラッグは選ぶだけで、動かすのはハンドルです。
- 配置モードで物を選ぶと「支点」が使えます。押している間は移動ハンドルが回転の中心を動かします（数値は設置のタブ。[小物・物体](PROPS-JA.md)）。

## 物を選ぶ・編集する（配置モード）

選ぶ：クリック、囲む、Ctrl（⌘）＋クリックで足す・外す。いくつか選ぶと、1つの物の支点を中心に、まとめて動かし、X・Y・Z の軸でまとめて回せます。中心になるのは最後に足した物で、Ctrl＋Shift＋クリックでほかの物に変えられます（選択を外すと元に戻ります）。

Ctrl＋人体をクリック（配置モード）：腰を選んで、人物全体を動かします（そのままドラッグで床の上を動き、3軸ハンドルなら矢印と輪で）。

| 操作 | キー | 図の左のボタン |
|------|------|---------------|
| 外す | Delete（Backspace） | 削除 |
| 切り取り・コピー・貼り付け | Ctrl＋X・C・V | 切り取り・コピー・貼り付け |

狭い画面（スマホ横向きなど）では、左のメニューが2列でも入りきらないので、「…」で3軸ハンドルと、カーソル・編集のボタンを入れ替えます。

## パース定規とガイド図形

定規のタブで1点・2点・3点透視の線を出します。設置のタブで「ガイドとして置く（パース定規）」にして図形を置くと、
定規の向きにそろったガイド図形になります（直方体・円柱・角柱・角錐など、いくつでも）。

- ガイドは定規を出しているときだけ見え、定規の色で描かれ、辺が消失点まで延びます。アタリ画像には入らず、定規の画像に入ります。
- 3軸ハンドルの矢印・四角は、ガイドの辺の向きに沿います。「変形」では引いた側の辺だけが延び、反対側は動きません（透視していない辺も、高さや幅を変えられます）。
- 前の版の「ガイド立方体」は、開くとガイドの直方体になります。

## 置く前の大きさ

設置のタブと装備のタブでは、置く前（持たせる前）に、プレビューの薄い破線を見ながら大きさを決められます。
図形は幅・高さ・奥行き（角柱・角錐は角の数と天面）、小物は大きさ・X・Y・Z と部位ごとの長さ。置くとその大きさになります。

## カメラ

カメラのタブの「カメラの向き」は左右・上下・傾き（角度）で、その場でカメラを回します。「カメラの位置」は左右・上下・前後（cm）で、向きを変えずにカメラを動かします。


| 操作 | すること |
|------|---------|
| ホイール | 拡大・縮小 |
| Ctrl＋Alt＋ホイール | レンズ（広角ほどパースが強い） |
| 中ボタン／Alt＋ドラッグ | カメラを回す（Shift＋で動かす、Ctrl＋で拡大） |
| テンキー 1・3・7 | 正面・右から・上から |
| 2本指（スマホ） | つまんで拡大・動かして移動 |
| カメラパッド（スマホ） | 左下で回す、右下で動かす、右端で拡大 |
