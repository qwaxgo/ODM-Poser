## 実装済み（2026-11-01）
- パース定規の立方体：延ばす辺は透視の点数に合わせる（1点：奥行きの4本、2点：＋左右の4本、3点：＋上下の4本）
- 横の図：カメラの上下の角度・傾きに関わらず水平（向きだけ追う）。線の色と、隠れ線の破線（正面のカメラから隠れる所）を反映
- 関節の限界：ポーズのタブにも同じスイッチ（画面右上と連動）
- 操作欄の位置：見出しの「操作欄」で右・左・上・下（上・下は高さ 40% でスクロール）。画面の幅いっぱいを使う（幅の上限を外した）
- スマホ横持ち（分割表示）：画面の約 2/3 を図に。モードはアイコンだけ、表示の切り替えは畳んで始まる
- 画面の表示スイッチを切り替えたときのお知らせは、操作欄ではなく図の左下にしばらく出る
- 作業ログ（見る › シーン › 作業ログ、画面左上の一覧ボタン）：操作ごとに時刻とした事を記録（新しい 100 件、このブラウザに保存）。どの時点にも戻せ、戻したことも記録される
- 両手持ち：もう片方の手の拳の中心を柄の持ち位置に合わせ、指の付け根の並びを柄の向きにそろえる。届かないときは持ち手を体へ寄せる
