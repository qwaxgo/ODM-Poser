# 縦長画面向け UI レイアウト

**対象デバイス:** タブレット、縦向きモニター（背が高い、幅が狭い画面）  
**日付:** 2026-11-05

## レイアウト構成

```
┌─────────────────────────────────────────────┐
│           キャンバス表示（上部）            │
│  （固定高さ、またはドラッグで調整可能）    │
└─────────────────────────────────────────────┘

┌─────────────┬────────────────────────────────┐
│  サイドバー │  メニューエリア（横スクロール）
│ （タブ、    │  [ツール1] [ツール2] ... →   │
│  縦に積み） │                              │
│             │  （左右にスクロール可能）    │
│ [タブ1]     │                              │
│ [タブ2]     │  タブに応じて内容が変更    │
│ [タブ3]     │                              │
│  ...        │                              │
└─────────────┴────────────────────────────────┘
```

## デザイン方針

### キャンバス（上部）
- 表示高さ：固定、またはユーザーがドラッグで調整可能
- 現在の作業内容を表示（ポーズ、画像など）
- ユーザーが下部メニューを操作中も見える

### サイドバー（下部左）
- **タブ（縦に積み重ねた）:** 現在のデザインを変更しない
  - 各タブはカテゴリー/モード
  - タブをクリックするとメニュー内容が切り替わる
  - 例：「ポーズ」「ジオメトリ」「ツール」「設定」
- 幅：狭め、タブレット/スマホ画面に対応

### メニューエリア（下部右、メインコンテンツ）
- **横並びレイアウト:** ボタン/コントロールが横に並ぶ
- **スクロール可能:** メニュー項目が収まらなければ左右スクロール
- タブごとに内容が変わる
- 例：タブ「ポーズ」→ ポーズ関連ツールが横に表示される

## インタラクション流れ

1. ユーザーが上部のキャンバスを見る
2. 左のサイドバーからタブを選択
3. メニューが更新され、関連ツールが表示される
4. 必要に応じてメニューを左右にスクロール
5. キャンバスは常に見える状態を保つ

## このレイアウトを選んだ理由

- **タブレット/縦向き画面:** 幅より高さが長い
- **見やすさ:** キャンバスが常に見える（スタッキングなし）
- **操作性:** タップ対象が大きく、タッチフレンドリー
- **拡張性:** 横スクロールで無制限のメニュー項目に対応可能

## 実装時の注意点

- **レスポンシブ対応:** 画面サイズに応じて適応（タブレット vs 大型モニター）
- **タッチ対応:** タブのタップ、メニューの横スワイプに対応
- **デスクトップ互換:** 横長/広い画面では従来のレイアウトに戻す
- **キャンバスサイズ調整:** キャンバスとメニュー間にドラッグハンドルを設置（オプション）
