# 小物・物体を足す

人物に持たせる・身に着ける小物と、床に置く物体（箱・壁・建物・柱など）の出し方です。
どれも線と丸の簡単な形で描かれ、アタリ画像にも入ります。

English: [PROPS.md](PROPS.md)

## 小物（装備のタブ）

1. 「種類」で分類（片手武器・銃・楽器・食器・帽子など）を選び、その下で小物を選ぶ。
   「プレビュー」がオンなら、出す前に置かれる場所が薄く表示されます。
2. ボタンを押す。

| ボタン | すること |
|-------|---------|
| 右手に持つ・左手に持つ | その手に持たせます。手の形も持ち方に合わせて変わります（両手で持つ物は、もう片方の手も添えます） |
| 身に着ける | 頭・胸・背中・腰・足などに着けます |
| 置く | 椅子・乗り物などを床に置きます。座る・乗る物は体も合わせます |

誰にも持たせずに床に置くときは、「設置」のタブで小物の分類を選んで「置く」を押します（下の「設置」の節）。
人物が持っている物・身に着けた物は、「人物」のメニューの全身図の下（人物の管理）でも見られ、そこで外せます。
作る › 人物 › リセットの「付随物」では、持ち物・身に着けた物、オーラ、ワイヤー、関節の固定のうちチェックしたものを、まとめて外すか
（「外す」）、付けたまま大きさ・色・向き・位置・ワイヤーの高さを初期値に戻せます（「大きさ・色などを戻す」）。床に単体で置いた物は含みません。

**持つ位置。** 手に持つ物は、手の形ごとに決めた支点に合わせて置かれます。握る形（剣・バット・銃など）では柄が指の輪の中に、
包む形（コップ・ボール・スマホなど）では手のひらに、つまむ形（ペン・箸など）では指先の間に来ます。
手の形をあとから変えると、その形の支点に移ります。

**出ている物**の一覧で選ぶと、次のことができます。

- 外す・背負う・床・物体に置く・手に持つ・身に着ける（置いた物をまた持つ）・接地させる
- 逆手にする、両手持ちのオンとオフ、体を合わせる（椅子・乗り物）
- ランスとガンランスは、持たせると脇に挟んで前へ突き出す構え（カウチ）になります。ガンランスは銃剣を付けた銃の形で、片手で持ちます。
- 長柄（槍・薙刀・ハルバード・棍）と棒は、装備のタブの「持ち方」で「握る」か「カウチ（脇に挟む）」を選べます。「持つ位置」で、握る場所を柄に沿って前後にずらせ、「↺ 持ち方と持つ位置を戻す」でこの小物の初期値に戻せます（どの小物にもあります）。
- 「棒（ただの棒）」を追加しました。
- 大きさ・回転（前後・ひねる・横）・ずらす（左右・上下・前後）、線の色を変える、「↺ 戻す」

### 大きさを3軸で変える

「サイズ」のタブの「小物の大きさ（3軸）」で、X・Y・Z をそれぞれ別に伸び縮みさせます（20〜400%）。
手に持つ物は Y が親指の向き（剣の刃）、Z が腕の向き（銃身）、X がそれと直角です。持つ所はそのままで、先の方が伸びます。
置く前の大きさは、プレビューの欄でも決められます。

### 部位ごとの長さ（柄と刀身など）

武器など、いくつかの部位に分かれる小物は、「サイズ」のタブの「小物の部位ごとの長さ」で部位を1つ選び、その長さだけを変えられます。
選んだ部位は図で太く表示されます。柄を伸ばすと刀身はその先へ動き、手で持つ所はそのままです。両手持ちのもう片方の手や銃剣も、一緒に動きます。

| 小物 | 部位 |
|------|------|
| 剣・刀・ナイフ・クナイ | 柄、刀身 |
| 斧・鎚・ハルバード | 柄、頭 |
| 槍 | 柄、穂先（槍身） |
| 大型ランス | 柄、槍身 |
| ガンランス（銃剣型） | 銃床、銃身、銃剣 |
| 両剣 | 柄、上の刃、下の刃 |
| 銃（ライフル・ショットガンなど） | 銃床、銃身 |
| 鉤爪 | （柄）、爪 |

「↺ この部位を戻す」「↺ すべての部位を戻す」で元の長さに戻ります。MOD の小物にも部位を付けられます（MOD の説明の `segs`）。

### 置いた物を動かす

床に置いた物（「置く」「単体で置く」「床・物体に置く」）は、**配置**モードでドラッグして動かします
（Shift＋ドラッグで上下、ホイールで向き）。3軸ハンドルでは、移動・回転と、X・Y・Z の大きさを変えられます。
3軸ハンドルを出しているときは、ドラッグは選ぶだけで、動かすのはハンドルです（ハンドルを隠すとドラッグで動きます）。
人物が何人いても、置いた物はどの人物を編集しているときでも動かせます。

## 物体（設置のタブ）

「物体（床・壁・建物・柱など）」で種類を選んで「置く」を押します。直方体・床・壁・建物・段差・角柱・円柱・角錐・円錐・支柱があり、
幅・高さ・奥行きを cm で決めます。接地をオンにすると、人物は物体の上にも立ちます。
配置モードでドラッグして動かし、3軸ハンドルで幅・高さ・奥行きを変えます。

### 設置（図形・床・壁・天井・小物をまとめて）

「設置」のタブの「置く物」で、「図形・床・壁・天井」か小物の分類（武器・道具・帽子など）を選び、種類を選んで「置く」を押します。
置いた物はすべて「置いた物」の一覧に並び、選ぶと次の欄で変えられます。

| 欄 | 図形・床・壁・天井 | 小物 |
|----|-------------------|------|
| 位置 | 左右・上下・前後 | 左右・上下・前後 |
| 回転 | X（前後に倒す）・Y（向き）・Z（横に倒す） | 同じ |
| 大きさ | 幅・高さ・奥行き（角柱・角錐は角の数と天面も） | 大きさ・X・Y・Z（手に持つときと同じ）、部位ごとの長さはサイズのタブ |

「接地させる」で、回転していても、いちばん低い所で地面や下の物の上に着けます。人物も、傾いた面の上に足元の高さを合わせて立ちます。
壁と天井も物体（板）なので、いくつでも置け、3軸で回転できます（前の版で配置タブにあった壁・天井は、開くと物体に移ります）。
配置モードでは、ドラッグと3軸ハンドル（移動・回転・変形）でも動かせます。

## 自分で足す（MOD）

エディタにない小物・物体の種類・オーラ・手の形は、MOD で足せます。小物は、円柱・箱・球・円盤・円錐・輪・半球・線を
cm で並べて作ります（画像や 3D モデルの読み込みではありません）。
書き方は [MODDING-JA.md](MODDING-JA.md) の「小物」と「追加する」にあります。

- 手に持つ物の原点は、握る所（柄の中心）です。`grip` で持つ所を指定することもできます
- `api.props.add(key, def)` で小物、`api.solids.addKind(...)` で物体の種類を足します
- MOD で足した物はポーズのファイルに保存され、その MOD がない人のエディタでも壊れずに開けます
