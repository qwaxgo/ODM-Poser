書き出しに含まれる、このツールに由来するもの（人形の線と丸、組み込みの小物・物体・オーラの形、組み込みのポーズ）について、

クレジットを書いてくれる場合は、たとえば次のように書けます（書かなくても構いません）。

```

```

### 気をつけること

- **MOD で足したもの**：MOD の小物・物体・オーラ・ポーズなどは、その MOD の作者が決めた条件に従います。
- **自分で読み込んだもの**：読み込んだポーズのファイルなど、ほかの人が作ったものの権利は、使う人が確かめてください。
- **書き出しで描いたもの**：書き出しの上に描いた絵や、書き出しから作った画像の権利は、作った人のものです。
- **無保証**：書き出したファイルは「そのまま」提供され、どんな保証もありません。
- **OpenPose 画像**：ControlNet などで使われる骨格の描き方（点と色）に合わせた画像です。
