# アプリとして使う（PWA）

立体人形装置は、ブラウザから「アプリ」として追加できます（PWA）。追加すると、

- ホーム画面・スタートメニュー・Dock などにアイコンが出て、自分のウィンドウで開きます
- 一度開いたあとは、ネットにつながっていなくても開けます（MOD とプリセットも、最後に読んだもの）
- ネットにつながっているときに開くと、自動で新しい版になります

English: [APP.md](APP.md)

## 条件

アプリとして追加できるのは、エディタを **https のサイト** か **このパソコン（localhost）** から開いたときだけです。
`web/editor/index.html` をファイルとして直接開いたときは追加できません（エディタとしてはそのまま使えます）。

## パソコン（Windows・Mac・Linux）

### ComfyUI を使っている場合

1. ComfyUI を起動して、ブラウザで `http://127.0.0.1:8188/odm_poser/editor/index.html` を開く
   （ノードの中の小さな窓からは追加できません。ブラウザのタブで開きます）。
2. 右上の「アプリとして追加」を押す（またはアドレスバーのインストールのアイコン）。

### ComfyUI なしで使う場合

1. エディタのフォルダで次を実行する：
   ```
   python tools/serve.py
   ```
2. 表示された `http://localhost:8765/web/editor/` をブラウザで開き、「アプリとして追加」を押す。

追加したあとは、`tools/serve.py` を止めてもアプリは開けます（新しい版にしたいときだけ、もう一度起動して開きます）。

### ブラウザごとの違い

| ブラウザ | 追加のしかた |
|---------|------------|
| Chrome・Edge・Vivaldi・Brave | 「アプリとして追加」ボタン、またはアドレスバーのインストールのアイコン |
| Safari（Mac） | メニュー「ファイル」→「Dock に追加」（ボタンを押すと案内が出ます） |
| Firefox | アプリとしての追加には対応していません（ブラウザのタブのまま使えます） |

## スマホ・タブレット（iPhone・iPad・Android・Kindle）

スマホやタブレットでは **https のサイト** に置いたエディタが必要です。

1. エディタの `web` フォルダ（MOD も使うなら `mods` フォルダも）を、https の静的サイトに置く。
   GitHub Pages・Cloudflare Pages・Netlify などで置けます。エディタの場所は `https://（サイト）/web/editor/` です。
   - 置いたものはそのサイトで誰でも見られるようになります。非公開の MOD を置くときは注意してください。
   - MOD を置くときは、置く前に `python tools/make_mods_list.py` を実行して `web/mods.js` を作ります。
   - GitHub Pages は、非公開のリポジトリからは有料プランでのみ使えます。
2. スマホ・タブレットでそのアドレスを開き、追加する：

| 端末 | 追加のしかた |
|------|------------|
| iPhone・iPad（Safari） | 共有ボタン（□↑）→「ホーム画面に追加」（「アプリとして追加」ボタンを押すと案内が出ます） |
| Android（Chrome・Edge・Galaxy の Samsung Internet など） | 「アプリとして追加」ボタン、またはメニュー →「アプリをインストール」「ホーム画面に追加」 |
| Kindle タブレット（Silk） | メニュー →「ホーム画面に追加」（Silk の版によっては、ブラウザのまま使います） |

同じネットワークのスマホから、`python tools/serve.py --lan` で表示されたアドレスを開くこともできます。この場合は https ではないので、
アプリとしては追加できず、ブラウザのまま使います。

## 更新とオフライン

- アプリは、開いたときにネットからエディタ・MOD・プリセットを読み、読んだものを端末に残します。
- ネットにつながっていないときは、残したものを使って開きます。
- 新しい版を置いたら、ネットにつながった状態でアプリを開き直すだけで切り替わります。

## うまくいかないとき

| 症状 | 原因と対処 |
|------|-----------|
| 「アプリとして追加」ボタンが出ない | ファイルとして開いている（https か localhost で開く）、すでに追加済み、Firefox、ノードの中の窓で開いている、のどれか |
| スマホで追加できない | https で開いていない。https のサイトに置く |
| 新しい版にならない | ネットにつながった状態でアプリを開き直す。まだなら、アプリを閉じてもう一度開く |
| MOD が出ない | サイトに `mods` フォルダと `web/mods.js` を置いたか確かめる（`tools/make_mods_list.py`） |
