# 書き出し（画像・OpenPose・ポーズのファイル）

作ったポーズは、メニューの「書き出し」から画像やファイルに保存します。

English: [EXPORT.md](EXPORT.md)

## 大きさ

| 欄 | すること |
|----|---------|
| 比率 | 1:1・3:4・16:9・A判／B判など。「比率を指定」で横と縦の比を自由に |
| 長辺 | 比率を選んだときの長い辺のピクセル数 |
| 幅・高さ | 書き出す画像の大きさ（ピクセル）。直接書くと比率は「自由」になります |

前の画面（カメラ）の枠が、この大きさの比率になります。枠の中に見えているものがそのまま書き出されます。
端末が大きな画像を描けないときは、描ける大きさまで小さくして知らせます。

## 書き出すもの

| ボタン | 中身 | 使い道 |
|-------|------|-------|
| アタリ画像 | 白地に、人物の線と丸、小物（簡単な形）、オーラ | 下描き、img2img |
| OpenPose 画像 | 黒地に、体の 18 点と両手の 21 点ずつを標準の色で | ControlNet（OpenPose） |
| ポーズ（.json） | 人物・小物・物体・床と壁・カメラなど、いまの状態すべて | あとで続きを編集する、ほかの人に渡す |
| 構図の画像 | 下の「構図の画像に含める」で選んだものだけ | 背景や構図の下描き |

画像は保存する前に全体が表示されます。「保存する」を押すと保存し、「やめる」で戻ります。
アプリ版（[DOWNLOAD-JA.md](DOWNLOAD-JA.md)）では、「名前を付けて保存」の窓で保存先を選びます。

### 構図の画像

「構図の画像に含める」で、人物・小物・物体・環境（床・壁・天井）・定規・オーラを一つずつ選べます。
背景は「白」「透明」「テーマ」（画面と同じ色）から選びます。透明にすると、線だけの画像になります。

### 書き出す人物

人物が2人以上いるときは、「書き出す人物」で「全員」か、一人だけを選べます。
一人だけにすると、アタリ・OpenPose・構図の画像に、その人物（と持っている物）だけが描かれます。
床に置いた物・物体・床と壁は、どちらでも描かれます。

## ポーズのファイルを開く

「読込」の「ポーズのファイルを開く」で、書き出したポーズ（.json）を開きます。人物・小物・物体・カメラも元に戻ります。
前の版で保存したファイルも開けます。

## SNS に投稿・リンク

「SNS に投稿」の欄から、アタリ画像つきで X・Bluesky・Misskey・Mastodon などに投稿できます。
「編集データ入りのリンク」をオンにすると、リンクを開いた人のエディタに同じ人物・小物・カメラが出ます。
「リンクをコピー」でリンクだけを取ることもできます。
