# ポーズを足す（プリセット）

ポーズは、関節をドラッグして作るほかに、プリセットから始められます。

English: [POSES.md](POSES.md)

## 組み込みのプリセット

メニューの「プリセット」に、立ち・A ポーズ・T ポーズなど、手で作った基本のポーズが並んでいます。
選んで「このポーズにする」を押すと、そのポーズになります。体格（骨の長さ・太さ）と立っている場所はそのままです。

## ユーザープリセット（自分のポーズ集）

自分で用意したポーズのファイルを読み込むと、「ユーザープリセット」に並びます。何千件あっても、分類と検索で探せます。

1. 「プリセット」の「ファイルから読込」を押し、ポーズ集の `.json` を選ぶ（いくつでも選べます）。
2. 分類を選ぶか、検索欄に名前を入れる（ひらがな・カタカナ・英語の大文字小文字を区別しません）。
3. 一覧で選んで「このポーズにする」（ダブルクリックでも）。「ランダム」で一つ選びます。

ユーザープリセットからは**骨の向きだけ**を取り込みます。体格はいまの人物のままなので、どんな体格のポーズ集でも使えます。

### ファイルの形

ポーズのリストを JSON で書きます（`{"presets": [...]}` でも同じです）。

```json
[
  {"group": "立ち", "name": "腕組み", "P": [[0, 95, 0], [0, 111, 0], ...]},
  {"group": "座り", "name": "体育座り", "P": [...]}
]
```

| 項目 | 意味 |
|------|------|
| `group` | 分類（なければファイル名） |
| `name` | 名前（検索に使います） |
| `P` | 関節の位置 [x, y, z]（cm、y が上、人物は +z を向く）。21 関節か、手のない最初の 19 関節 |

関節の順番は、腰・ウエスト・胸・首・頭・右肩・右肘・右手首・左肩・左肘・左手首・右股・右膝・右足首・右つま先・
左股・左膝・左足首・左つま先・右手・左手です。書き出したポーズのファイル（.json）の `P` も同じ形なので、
作ったポーズを並べてポーズ集にできます。

## MOD で足す

MOD からは、組み込みのポーズ（`api.poses.add`：立った姿勢から関節を何度回すか）と、
ユーザープリセット（`api.presets.add`）を足せます。毎回同じポーズ集を使うときは、MOD にしておくと読み込みが要りません。
詳しくは [MODDING-JA.md](MODDING-JA.md) にあります。ComfyUI では、決まったフォルダに置いたポーズ集が自動で並びます（[COMFYUI-JA.md](COMFYUI-JA.md)）。

ほかの人が作ったポーズ集を使うときは、その配布条件に従ってください。
