# Phase 1：メニュー体系の再構成

## 目標
上部バー + サイドメニューを 11 個の独立メニュー単位に再構成し、コンテキストメニュー、全身図ビジュアル、PC/スマホレスポンシブ対応を実装する。

## 新しいメニュー体系（11 個）

1. **人体に付随するオブジェクト召喚** - 気、オーラ、プラズマ、背負う道具など
2. **人体から離れたオブジェクト召喚** - 背景、床、家具など
3. **ポーズ調整** - 関節操作、左右対称、手の形など
4. **出ている人物・オブジェクト管理** - 現在のシーン内のすべての要素を一覧・管理
5. **体格調整** - 身長、肩幅、ウエスト、ヒップ、全体スケールなど
6. **配置調整** - 位置、向き、高さの調整
7. **色調整** - 線の色、肌色など（一元管理）
8. **サイズ調整** - 各部位の縦幅・横幅、武器の長さ・太さなど
9. **出力と共有** - 書き出し、SNS共有、プリセット保存
10. **カメラとパース** - レンズ、向き、高さ、傾き、カメラ記憶
11. **定規** - パース定規、直方体ガイド
