立体人形装置 ODM Poser（Windows）

ODM-Poser.exe をダブルクリックすると起動します。インストールは要りません。
MOD は、この exe の隣の mods フォルダに入れます（mods/README.txt）。

- 署名のないアプリなので、初めて起動するとき Windows が「PC を保護しました」と出すことがあります。
  「詳細情報」→「実行」で起動できます。
- 画面の表示に WebView2 ランタイムを使います。Windows 11 と、新しい Windows 10 には入っています。
  起動しないときは、Microsoft の WebView2 ランタイム（Evergreen）を入れてください。
- 使い方・MOD の作り方：https://apps.qwaxgo.com/ODM-Poser/docs/
- ライセンス：MIT（LICENSE）


ODM Poser (Windows)

Double-click ODM-Poser.exe to start it. Nothing to install.
Put mods in the mods folder next to this exe (mods/README.txt).

- The app is not code-signed, so on the first start Windows may say it protected your PC:
  click "More info", then "Run anyway".
- It draws its window with the WebView2 runtime, which Windows 11 and recent Windows 10 have.
  If it does not start, install Microsoft's WebView2 Runtime (Evergreen).
- How to use it, writing mods: https://apps.qwaxgo.com/ODM-Poser/docs/
- Licence: MIT (LICENSE)
