立体人形装置 ODM Poser の MOD フォルダ

ここに MOD（*.js、または MOD のリポジトリのフォルダ）を入れます。
アプリは起動するときに、このフォルダの MOD を読み込みます（入れたあとは、アプリを開き直してください）。
アプリの MOD の欄の「フォルダから」でも、好きなフォルダの MOD を読み込めます。

MOD はエディタの中で自由に動くプログラムです。信頼できるものだけを入れてください。
MOD の作り方：https://apps.qwaxgo.com/ODM-Poser/docs/


ODM Poser's mods folder

Put mods here (*.js files, or the folder of a mod repository).
The app loads the mods of this folder when it starts (after adding one, open the app again).
"From a folder" in the app's MOD panel loads the mods of any folder too.

A mod is a program that can do anything inside the editor: put in only mods you trust.
Writing mods: https://apps.qwaxgo.com/ODM-Poser/docs/
