立体人形装置 ODM Poser の MOD フォルダ

ここに MOD（*.js、または MOD のリポジトリのフォルダ）を入れます。読み込ませ方は2つあります。

1. 一つ上のフォルダの mods.js に、ファイル名を1行ずつ書く（毎回、自動で読み込みます）
2. エディタの MOD の欄で「フォルダから」を押し、この mods フォルダを選ぶ
   （Chrome と Edge はフォルダを覚えます。次からは読み取りの許可を聞かれたら「読み込む」を押します）

MOD はエディタの中で自由に動くプログラムです。信頼できるものだけを入れてください。
MOD の作り方：https://apps.qwaxgo.com/ODM-Poser/docs/


ODM Poser's mods folder

Put mods here (*.js files, or the folder of a mod repository). Two ways to load them:

1. Write each file name on a line in mods.js, one folder up (loaded every time)
2. In the editor's MOD panel, press "From a folder" and pick this mods folder
   (Chrome and Edge remember the folder; next time, press "Load" if the browser asks to allow reading it)

A mod is a program that can do anything inside the editor: put in only mods you trust.
Writing mods: https://apps.qwaxgo.com/ODM-Poser/docs/
